# NETRA AI business model site

Open `index.html` in a modern browser. No build step is required. The logo is supplied as an SVG with a 4K-sized viewBox so it stays crisp when scaled. The page uses optional web fonts from Google Fonts and includes local fallback fonts.

The `research/` folder contains the supplied presentation and research PDFs. The ARR paths are illustrative planning scenarios, not forecasts.
